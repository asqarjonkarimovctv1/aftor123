YT Timeline 1.6.0 — Windows x64

O'RNATISH
1. ZIP arxivni to'liq oddiy papkaga oching.
2. Premiere Pro'ni yoping.
3. Install-Windows.cmd faylini ishga tushiring. Administrator huquqi talab qilinmaydi.
4. Premiere Pro'ni qayta oching:
   Window > Extensions (Legacy) > YT Timeline.
5. Loyihangizni .prproj fayliga saqlang va kerakli sequence'ni oching.

YOUTUBE BRAUZERI
Paneldagi "YouTube'ni ochish" tugmasi plaginning alohida WebView2 oynasini ochadi.
Qidiruvdan videoni toping, so'ng "Yuklash bo'limiga yuborish" tugmasini bosing.
Panelga qaytib "YUKLASH > TIMELINE" tugmasini bosing.
Brauzer CEP paneliga dock qilinmaydi. Tizimning oddiy brauzeri ochilmaydi.
Microsoft Edge WebView2 Evergreen Runtime talab qilinadi:
https://developer.microsoft.com/microsoft-edge/webview2/
Brauzer moduli .NET runtime'ini o'z ichiga oladi; .NET SDK o'rnatish kerak emas.

LOYIHA AUDIOLARI
Yangi MP3 fayllar Downloads\YT Timeline\<loyiha nomi va identifikatori> ichida saqlanadi.
Panelda faqat joriy loyiha tarixi chiqadi. Ro'yxatni scroll qilish mumkin.
"+" tugmasi mavjud audioni qayta yuklamasdan timeline'ga qo'shadi.
Tarixni tozalash MP3 fayllarni o'chirmaydi.
Eski yuklamalar o'z joyida qoladi. Ular loyiha ichida import qilingan bo'lsagina
shu loyiha ro'yxatiga ko'chadi. Fayllar avtomatik ko'chirilmaydi.

YUKLASH TEZLIGI
Audio Samplecut orqali tayyorlanadi; YouTube oynasi bu xizmatni almashtirmaydi.
Serverdagi davomiylik va tezlik cheklovlari saqlanadi.
Faqat foydalanish huquqiga ega bo'lgan materiallarni yuklang.
