# Windows download

[Download YT Timeline 1.6.0 for Windows x64 (ZIP, about 45 MB)](./Salos-YT-Timeline-Windows-1.6.0.zip?raw=true)

Extract the entire ZIP, close Premiere, then run `Install-Windows.cmd`. Restart Premiere and open **Window > Extensions (Legacy) > YT Timeline**. The YouTube companion requires Microsoft Edge WebView2 Runtime; installation instructions are included in `READ-ME-FIRST.txt`.

This is a test package: automated checks and cross-compilation passed, while the actual Premiere/WebView2 workflow still requires a Windows smoke test. The older `Setup-1.5.3.exe` does not include the new browser or project library.

The `.zip.sha256` file contains the download's checksum.
